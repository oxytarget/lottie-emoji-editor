# Emoji Studio — редактор анімованих Lottie-емодзі

MVP веб-застосунку (і Telegram Mini App) для створення анімованих емодзі в стилі Auto Emoji Maker:
вводите текст **або завантажуєте SVG-логотип**, обираєте персонажів, кольори та розмір і отримуєте готові
файли `.tgs` для Telegram (або Lottie JSON). Усе працює в браузері, без сервера, акаунтів і кабінетів.

## Можливості

- **Текст → вектор.** Текст перетворюється на контури (`opentype.js`), тож у файлі немає текстових шарів, які Telegram не підтримує.
  13 вбудованих шрифтів із кирилицею (Nunito, Rubik, Unbounded, Montserrat, Russo One, Dela Gothic, Lobster…), до 3 рядків,
  обводка, міжлітерний і міжрядковий інтервали, ВЕЛИКІ ЛІТЕРИ. Можна завантажити свій шрифт (TTF / OTF / WOFF).
- **SVG-логотипи.** Імпорт `path`, `rect`, `circle`, `ellipse`, `line`, `polyline`, `polygon`, `<use>`, вкладених `<svg>`, трансформацій,
  CSS-класів із `<style>`, прозорості, `fill-rule`, обводок і **лінійних/радіальних градієнтів**. Режими «оригінальні кольори» або «перефарбувати»,
  плюс контур-наліпка навколо лого. SVG ніколи не вставляється в сторінку (безпечно щодо скриптів у файлі).
- **22 анімовані персонажі:** класика, стрибок, серце, зірка, вогонь, корона, репліка, блиск, орбіта, блискавка, кільце, стрічка, «вау»,
  свято, наліпка, бум, сонце, монета та 4 шаблони «лише лого» (політ, оберт, пульс, желе).
- **Кольори.** Готові розфарбовки (Mono, Nebula, Lava, Ocean, Mint, Candy, Gold, Neon, Paper), випадкові палітри (🎲),
  заливка / обводка / акцент персонажа з градієнтами (лінійний з поворотом або радіальний), товщина обводки.
- **Розмір і висота** тексту/лого, живий перегляд на світлому, темному та прозорому фоні, а також «у чаті».
- **Свій Lottie / TGS.** Імпортуйте готову анімацію — редактор розбирає її на **частини** (шари, шари всередині композицій,
  групи фігур) з мініатюрами й сам підсвічує схоже на текст/лого. Будь-яку частину можна сховати, а текст/лого — **замінити своїм**:
  новий текст чи SVG-лого стає на місце старого й рухається за його анімацією. Також можна змінити будь-який колір або накласти
  свій текст/лого поверх. Текстові шари й зображення (їх не підтримує Telegram) позначаються попередженням.
- **Експорт:** `.tgs` (gzip + `"tgs": 1`) або Lottie JSON, окремо чи одним ZIP. Для кожного файлу перевіряються ліміти Telegram:
  512×512, 60 FPS, ≤ 3 с, ≤ 64 КБ. Типовий розмір — 1–5 КБ.
- Інтерфейс українською, російською та англійською. Налаштування зберігаються в `localStorage`.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # юніт-тести (vitest)
npm run build      # типізація + продакшн-збірка в dist/
npm run preview    # перегляд збірки
```

Потрібен Node.js 20+.

## Як додати емодзі в Telegram

1. Відкрийте бота [@Stickers](https://t.me/Stickers) і надішліть `/newemojipack`.
2. Оберіть «Анімовані емодзі» та надішліть завантажені файли `.tgs`.
3. Для кожного вкажіть емодзі-відповідник, потім `/publish`.

## Telegram Mini App

`dist/` — це статичний сайт, тож його можна розмістити на будь-якому HTTPS-хостингу. У репозиторії налаштовано
**GitHub Pages** (`.github/workflows/pages.yml`): кожен пуш у `main` проганяє тести, збирає застосунок і публікує його на
`https://oxytarget.github.io/lottie-emoji-editor/`. Запустити деплой вручну можна з вкладки *Actions → Deploy to GitHub Pages → Run workflow*.

Одноразове налаштування: *Settings → Pages → Build and deployment → Source: **GitHub Actions***.
Для приватного репозиторію Pages доступні лише на платних тарифах GitHub (Pro / Team); на безкоштовному — зробіть
репозиторій публічним або використайте Netlify, Vercel чи Cloudflare Pages (команда збірки `npm run build`, тека `dist`).

Потім у [@BotFather](https://t.me/BotFather) → *Bot Settings → Menu Button / Configure Mini App* вкажіть URL застосунку.

### Бот

**Налаштування бота** (`.github/workflows/telegram-bot.yml`, запуск вручну): кнопка меню «Emoji Studio» відкриває редактор,
команда `/start`, опис і короткий опис (uk / ru / en). Потрібен секрет `TELEGRAM_BOT_TOKEN`
(*Settings → Secrets and variables → Actions*). Токен ніколи не комітьте в репозиторій.

**Бекенд бота** (`api/` + `worker/src/app.ts`, звичайні Web `Request → Response`):
- `POST /api/send` — у Telegram кнопка «Надіслати в чат» у вікні експорту відправляє файли сюди; бекенд перевіряє
  підпис `initData` і бот надсилає `.tgs` файлами користувачу в чат (альбомами по 10). Якщо користувач ще не натискав Start,
  Mini App попросить дозвіл на повідомлення й повторить спробу;
- `POST /api/pack` — бот сам створює **емодзі-пак** користувача (`createNewStickerSet`, тип `custom_emoji`, власник — користувач)
  або дописує в пак, створений раніше (`addStickerToSet`, до 200 емодзі). У вікні експорту задаються назва паку й звичайний емодзі
  для кожного персонажа; після створення бот надсилає посилання `t.me/addemoji/...`. Файли перетворюються на полотно 100×100
  (формат кастомних емодзі); якщо Telegram відхилить його, бекенд автоматично повторить із 512×512;
- `POST /api/telegram` — вебхук: на `/start` бот відповідає привітанням і кнопкою «Відкрити редактор»;
- `GET /api/health` — перевірка, чи задано токен.

#### Варіант 1: Vercel (рекомендовано, без ключів API)

1. https://vercel.com/new → *Continue with GitHub* → імпортуйте `lottie-emoji-editor` (Framework Preset визначиться як Vite).
2. У *Environment Variables* додайте `TELEGRAM_BOT_TOKEN` = токен бота → *Deploy*.
3. Адреса бекенда для продакшн-збірок записана в `.env.production` (`VITE_BOT_API_URL=https://lottie-emoji-editor.vercel.app`) —
   і GitHub Pages-версія, і Vercel надсилають файли через нього. Для іншого проєкту змініть цю адресу.
4. *Actions → Set up Telegram bot → Run workflow*, у полі `backend_url` вкажіть `https://<проєкт>.vercel.app` —
   зареєструється вебхук для `/start`.

#### Варіант 2: Cloudflare Workers

Workflow `.github/workflows/bot-backend.yml` деплоїть `worker/`, передає йому токен, реєструє вебхук і перезбирає сайт.
Секрети репозиторію: `TELEGRAM_BOT_TOKEN`, `CLOUDFLARE_API_TOKEN` (шаблон **Edit Cloudflare Workers** на
https://dash.cloudflare.com/profile/api-tokens), `CLOUDFLARE_ACCOUNT_ID` (32 символи в адресі панелі після `dash.cloudflare.com/`).
Перед першим деплоєм відкрийте https://dash.cloudflare.com/?to=/:account/workers/onboarding, щоб створився піддомен `*.workers.dev`.

Локально: `cd worker && npm install`, створіть `worker/.dev.vars` з `TELEGRAM_BOT_TOKEN=...` і `ALLOWED_ORIGINS=http://localhost:5173`,
запустіть `npx wrangler dev`, а сайт — `VITE_BOT_API_URL=http://127.0.0.1:8787 npm run dev`.

Скрипт `telegram-web-app.js` підвантажується лише тоді, коли сторінку відкрито як Mini App (є параметри `tgWebApp*`):
застосунок розгортається на весь екран, підхоплює мову користувача та дає тактильний відгук.
Деякі клієнти Telegram (зокрема iOS) блокують завантаження файлів із міні-застосунку, тому у вікні експорту є кнопка «Відкрити в браузері».

## Структура

```
src/
  lottie/       генерація Lottie: кейфрейми, шейпи, Безьє, заливки/градієнти, збирання, експорт TGS/ZIP, імпорт, перефарбування
                і розбір імпортованих анімацій на частини (parts.ts)
  content/      текст → контури (opentype.js), SVG → контури, каталог шрифтів
  templates/    анімовані персонажі (builtin.ts) і векторні деталі (kit.ts)
  state/        стан (zustand), пресети, компіляція у Web Worker
  components/   інтерфейс
  lib/          інтеграція з Telegram Mini App і надсилання файлів у чат
api/            функції Vercel (бекенд бота)
worker/         спільний код бекенда + вхід для Cloudflare Workers
scripts/        налаштування бота й вебхука
```

Ключова ідея: будь-який контент (текст чи лого) спершу перетворюється на незалежні від роздільності контури (`VectorArt`),
а шаблон лише задає «слот», куди контент вписується, і анімацію. Згенеровані файли використовують тільки те, що підтримує rlottie
(рендерер Telegram): шейп-шари, null-шари для анімації, групи, контури, еліпси, прямокутники, заливки, обводки й градієнти.
Під час розробки всі шаблони перевірено рендерингом у rlottie.

## Обмеження MVP

- Текст усередині SVG, растрові зображення, маски, `clip-path`, фільтри й візерунки пропускаються (редактор про це попереджає) —
  переведіть текст у криві та спростіть файл перед імпортом.
- Дуже деталізовані логотипи можуть перевищити 64 КБ — розмір видно на кожній картці.
- Лігатури й складне шейпінг-письмо (арабське, деванагарі) не підтримуються; емодзі-символи в тексті ігноруються.
